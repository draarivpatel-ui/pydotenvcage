# Good first issues

These are bounded ways to improve pydotenvcage after its public launch.

1. Add parser compatibility notes for dotenv dialects used by popular Python frameworks.
2. Expand schema types with duration, comma-list, or semver validators behind strict bounds.
3. Improve documentation for migrating from insecure shell-sourced env files.
4. Add additional secret-shape detectors with low false-positive rates.
5. Add more regression fixtures for Unicode and line-ending attacks.

Do not add runtime dependencies. Do not add tests containing real secret literals.
